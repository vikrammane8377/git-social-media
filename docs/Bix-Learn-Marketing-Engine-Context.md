AI language reviewer requirement and planning validation

The owner explicitly requested an AI reviewer such as GPT-5.6 Sol because he will be the sole human manager. The saved companion specification is Bix-Learn-AI-Language-Reviewer.md. It defines a reusable review role parameterized by audience, source language, target learning language, locale, and learner level. This avoids creating 14 separate ongoing agents.

Proposed model: GPT-5.6 Sol. Its current official API documentation confirms text and image inputs, structured outputs, and no native audio or video input. Pronunciation, intonation, and complete video checks therefore require a separate supported audio/video assessment process; a transcript or sampled frame cannot establish them. Source checked on 22 September 2026: https://developers.openai.com/api/docs/models/gpt-5.6-sol

A GPT-5.6 Sol sub-agent was used in this planning session to review instructions and four synthetic text examples. It caught the embarrassed/pregnant false friend, corrected English age phrasing, accepted valid Spain-specific plural forms, and rejected unsupported fluency and free/unlimited product claims. This is a limited text demonstration, not a multilingual accuracy benchmark or a deployed reviewer.

The proposed owner-facing review includes an English explanation, exact corrections, regional notes, product-claim evidence, unresolved questions, and checks not performed. A text pass never means publication approval. Fixes must be reviewed in the resulting revision; missing audio assessment must remain visible. Use a second independent check or a verified simpler alternative for uncertain language, and hold unresolved material instead of silently approving it.

No persistent agent, API connection, automatic review trigger, or website has been deployed. The project remains in the requested research and planning phase.
